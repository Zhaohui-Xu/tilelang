# Replaying the measurements
Use the MACA runtime described in manifest.json. Benchmark logic runs on C500. The TileLang repository includes its MIT license in LICENSE. The measured dense baseline is tile-ai/tilelang-metax commit 90d49f353ec88bd0d346474f143003d865dd3b79 at examples/deepseek_mla/example_mla_decode.py. Copy it to the experiment directory as upstream_example.py.

The public example on branch example/c500-mla-decode contains the final callable and benchmark CLI. Running its README commands is sufficient for a normal comparison. In the private experiment archive, the following stages retain the data used for selection and the held-out comparisons.

- batchperf.json contains the original H16/64-split candidate's batch 2/4 comparisons. batch_suite.py uses its historical public helper at c7a3392, stable_mla.py from the archive, and the fixed dense baseline.
- For amd.json and small.json, use the kernel, harness and measure.py in measured-source. Run python measure.py amd and python measure.py small beside upstream_example.py. These stages screen legal splits and include the native paged interface.
- wide_bench.py uses those measured versions and wide_candidate.py, reads amd.json and writes wide.json. It screens two pilot shapes and tests retained wide schedules across the large grid. confirm.py reads small.json and writes confirm.json. It refines both contestants and then times small-batch calls with 200 warmups and 2000 iterations.
- For release_check.py use the integrated-source factory and harness, the measured-source kernel renamed measured_kernel.py, and wide_candidate.py. It reads confirm.json, amd.json and wide.json. release.json and unseen.json contain its results. crossover.py measures previously unscreened batch and head counts with this factory.
- For default_pairs.py use the final public factory and harness, upstream_example.py, confirm.json, release.json and cross.json. It writes defaults.json, default_edges.json and cross_defaults.json. regression.py repeats the original correctness matrix with the public default factory. transition.py compares an additional low-workload split rule with the measured version.
- All native paged times exclude conversion of the four dense inputs into packed query/paged cache, construction of the identity page table and scheduler metadata. Native calls also return LSE. Dense timings include output and intermediate workspace allocations.
- previous_public.py is the default factory measured by default_pairs.py. The final rule subsequently reduces wide-kernel split traffic at intermediate work sizes. adopt_check.py compares old/new generated device and host code hashes at the published grid and boundary points, and uses the final public factory with new inputs to measure changed schedules.
The release sweep included head tile 128 after a real 1024-thread smoke test. Set the head128.ok marker only after that smoke passes when replaying the frozen sweep. The final two opt-in CLI calls use --tune, H=128, the one-split dense baseline, seeds=3, warmup=10, iterations=50, on B16/N2048 and B9/N4096.

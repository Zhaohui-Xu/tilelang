# Input layout and MACA dispatch check
At B1/H16/N2049 the first invocation exited 139 for KV produced by a device conversion without an explicit contiguous layout. Cross-checking the same candidate with two and four compile arguments gave the same outcome for each input layout. The working key strides were (1049088,512,512,1). The failing key strides were (1049088,1,1049088,2049), despite both tensors having shape (1,2049,1,512). Positional-key strides differed in the same way. The FP16 dense ABI requires row-major contiguous tensors. Restoring explicit .contiguous() after conversion passed all smoke checks, including both H16 and H128. The public benchmark checks input contiguity before dispatch. This isolates the failing layout/adapter combination without attributing the fault to a specific compiler component.
